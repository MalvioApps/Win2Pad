## Media keys

- **Media keys work on the iPad**: volume, mute, play/pause, next and previous track, and Home
  and Spotlight search on keyboards with those keys.

**Pair the iPad again once** for them: on the iPad, *Settings → Bluetooth → (your PC) → Forget
This Device*, then pair again with Win2Pad running. Keyboard and mouse keep working without it.

[Code signing policy](https://github.com/MalvioApps/Win2Pad#code-signing-policy)
