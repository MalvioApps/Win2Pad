First public release.

- Move the pointer across the edge of any screen onto the iPad and back, at the matching point.
- Place the iPad visually in Screens, with magnets and an adjustable shared edge.
- Automatic calibration from the iPad model, with an optional fine-tune in Safari that measures the pointer acceleration.
- Each iPad remembered with its calibration, orientation and pointer speed.
- Keys sent by physical position: any keyboard layout works, AltGr included.
- Tray icon and floating indicator that change colour with where the input is.
- Automatic updates from GitHub releases.
