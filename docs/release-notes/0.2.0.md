## Paste from the PC and media keys

- **Ctrl+V on the iPad types what you copied on the PC.** Text only, up to 5,000 characters,
  through the iPad's keyboard layout (accents included). If you copied on the iPad more recently,
  Ctrl+V pastes that instead, as usual.
- **Media keys work on the iPad**: volume, mute, play/pause, next and previous track, and Home
  and Spotlight search on keyboards with those keys.

**Pair the iPad again once** for the media keys: on the iPad, *Settings → Bluetooth → (your PC)
→ Forget This Device*, then pair again with Win2Pad running. Keyboard and mouse keep working
without it.
